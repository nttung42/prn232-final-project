[Deferred] Mobile Responsive Views
Phân hệ quản trị Provider và Admin tạm thời chưa ưu tiên tối ưu giao diện Mobile theo quyết định của dự án, tập trung hoàn thiện tối đa trải nghiệm Web Desktop cho các bảng biểu và ma trận phức tạp.

[Convention] Role-based Authorization and Route Protection
Hệ thống phân quyền 3 cấp độ đồng bộ giữa Backend JWT Claims và Frontend Client Guard (site-api.js): "Admin" (toàn quyền duyệt cơ sở và quản lý tài khoản), "Provider" (quản lý cơ sở, sân, khung giờ và duyệt đơn), "Player" (tìm kiếm sân, đặt lịch và quản lý lịch sử).

[Convention] OData Query Filter Syntax
Backend EF Core và Microsoft.AspNetCore.OData yêu cầu tên thuộc tính viết hoa theo PascalCase trong query string. Mọi bộ lọc trên Frontend phải tuân thủ chuẩn: $filter=Status eq 'Approved', contains(tolower(District), '...'), $orderby=CreatedAt desc, và $top / $skip cho phân trang.

[Convention] Content Negotiation Media Types for Data Export
API xuất báo cáo đơn đặt sân đáp ứng chuẩn Content Negotiation qua HTTP Header Accept:
- text/csv: Xuất tệp tin bookings.csv (xử lý qua CsvOutputFormatter)
- application/xml: Xuất tệp tin bookings.xml (xử lý qua XmlSerializer)
- application/json: Xuất dữ liệu JSON thô
Frontend sử dụng helper triggerDownload để tải tệp trực tiếp về máy tính người dùng mà không cần reload trang.

[UI/UX Improvement] Live Matrix Peak Hour Highlighting
Ma trận đặt sân thời gian thực kế thừa thiết kế Stitch với các khung giờ cao điểm (17:00 - 20:00) được gắn nhãn sao vàng (★), nền màu hổ phách (amber-50) và hiển thị giá chênh lệch nhằm giúp người chơi dễ dàng nhận diện ca đông khách.
